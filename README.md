# Cztery Monety — Minecraft Java 1.21.3

Resource pack z teksturami czterech monet. Format paczki: 42.

Pobierz plik `CzteryMonety-ResourcePack-1.21.3.zip` z tego repozytorium. Nie używaj archiwum „Download ZIP” całego repozytorium jako resource packa.

## Ustawienia serwera

Wyłącz serwer i zastąp odpowiednie wpisy w istniejącym `server.properties` tym fragmentem:

```properties
resource-pack=https://raw.githubusercontent.com/hyg3376-maker/cztery-monety-resourcepack/main/CzteryMonety-ResourcePack-1.21.3.zip
resource-pack-sha1=a251e1f5bac3b7881e4006a0ec773e01ee988fe1
require-resource-pack=true
```

Zapisz plik i uruchom serwer. Ten fragment nie zastępuje całego pliku ustawień.

Paczka współpracuje z pluginem CzteryMonety na Minecraft 1.21.3.
